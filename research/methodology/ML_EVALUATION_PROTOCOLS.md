# Machine-Learning Evaluation Protocols

## Purpose

This document records the downstream classifier evaluation protocols used by the two notebooks. The protocols are intentionally distinct and are retained as originally conducted.

## Stable-FCI experiment

1. Validate the 4,920 × 173 binary dataset (41 disease indicators + 132 symptoms).
2. Create a stratified 80/20 split with random state 42: 3,936 train and 984 test.
3. Run Stable-FCI and select the 37-feature set on training rows only.
4. Tune each downstream classifier using five-fold stratified CV on the training rows and macro F1 as the selection score.
5. Fit the selected configuration on all 3,936 training rows.
6. Evaluate once on the 984-row held-out test set.

The all-symptom baseline uses 132 symptom features and the same split. Stable-FCI selection is performed once before classifier CV; the feature-selection operation is not repeated within each CV fold.

## STAR CI-selected experiment

1. Validate separate training disease/symptom matrices (4,920 rows) and external test disease/symptom matrices (42 rows).
2. Run disease-specific CI screening on the training matrices only.
3. Union disease-specific retained symptoms in original symptom-column order, producing 106 features.
4. Tune Logistic Regression, Random Forest, and XGBoost with five-fold stratified CV on the 4,920 training rows, using macro F1.
5. Fit each selected classifier on the training data and evaluate on the 42-row external test set.

The STAR all-symptom baseline uses 132 symptoms and the same supplied STAR split. XGBoost uses label encoding and verifies the encoder's class order against the class order used for probability interpretation.

## Metrics

- **Accuracy:** fraction of test predictions equal to the true class.
- **Macro precision/recall/F1:** compute each class metric and average classes equally, with zero-division handling as implemented in the notebooks.
- **Weighted F1:** average class F1 weighted by test support.
- **Top-k accuracy:** fraction of examples whose true class appears among the k highest model scores.
- **Macro one-vs-rest ROC-AUC:** reported in the Stable-FCI summaries.
- **Log loss:** reported for STAR Logistic Regression.

## Comparability

The Stable-FCI metrics use a held-out test set of 984 records generated by a stratified 80/20 split. STAR metrics use 42 separate external test records. These are not the same test observations or sample size. Do not rank the approaches by directly comparing their historical accuracy or F1 values.

The application comparison is different: it sends one live symptom input through each chosen saved model and reports each result separately. This can reveal agreement or disagreement for that input, but does not replace a common-protocol benchmark.
